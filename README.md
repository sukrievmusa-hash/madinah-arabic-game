# madinah-arabic-game

Игра для изучения арабского по «Мединскому курсу», том 1: 143 слова из 10 уроков, 60 картинок из книги, 17 упражнений, включая грамматику учебника и голосовой ввод.

Вся игра — один файл: [`madinah_arabic_game.html`](https://sukrievmusa-hash.github.io/madinah-arabic-game/madinah_arabic_game.html). Открывать в Chrome, Edge или Safari; микрофон работает только по ссылке https.
